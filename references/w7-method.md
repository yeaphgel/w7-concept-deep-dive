# W7 概念审计速查

**读法**：七问是分析工具，不是每轮必须照抄的目录。先准确复述，分别说明确认、推测、未知。

| 项目 | 审计目标 | 关键反例 |
|---|---|---|
| W1 语言游戏 | 检查事实、身份、规范、比喻跨域偷换 | “项目没赚钱”不等于“我是失败者” |
| W2 人话翻译 | 删除术语观察信息损失 | “赋能增长”具体谁做了什么？ |
| W3 使用边界 | 正例、反例、边界案例 | 并非一切看见广告的人都是客户 |
| W4 偷换 | 识别推论断裂的位置 | 相关并非因果 |
| W5 反实体化 | 还原实际机制和主体 | “市场拒绝”→谁没买、为何没买 |
| W6 铰链 | 标记 3—5 个承重前提及证据状态 | “客户愿付费”是否已有成交证据 |
| W7 思想增量 | A 认知增量/B 观察框架/C 概念膨胀 | 命名改变但预测毫无变化 |

特别注意维特根斯坦式分析并非万能证伪仪。价值、宗教与人生基本信念不应伪装成统计命题，也不能仅因不可证伪就被简单宣判无意义。观察用户使用一个词时实际在做什么，而非假定只有一个隐藏的本质。
