## 审计报告

**原话真正的意思** → **核心 W7 发现（最多 3—5 项）** → **承重前提** → **有效部分** → **修订命题** → **可行的现实验证或开放问题** → **费曼三句**。

## 思想升级报告

**原命题** → **已有概念能解释什么** → **新区别** → **可能机制与证据分级** → **强反例** → **思想增量（A/B/C）** → **未解决问题** → **第零问**。

## 自我欺骗检查

把可观察事实、身份叙事、成本和未来选择分开；心理动机只能标注假说。对证据不足的问题答“目前无法判断”。

## ProbeMe 进行时

遵照 `probe-me` 原生会话和 `probe-ledger` 输出，不叠加 W7 模板。
