# 概念升级流程

输入一个概念时，优先回答：谁在什么情境中使用这个词？它把哪些不同任务压成同一词？去掉名字，现实剩下什么？

四项增量指标：
- **区分力**：能区分原先混用的不同情况。
- **解释力**：提出有证据约束的机制，而不只是重新命名。
- **预测/判断力**：带来可观察差异或更好的判断。
- **边界感**：明确不适用情况，愿意接受反例。

例：“获客”可能混合曝光、联系、合格销售机会、付费成交。升级不是武断宣称“获客的本质就是信任”，而是看行业、价格、决策周期等条件区分注意力、可信证据、转化摩擦。低价冲动消费和复杂企业咨询可能需要不同定义。

标注结论强度：已证实事实 / 较可信解释 / 待检验假说 / 价值选择 / 纯比喻。找到更简单准确的旧说法时，不必创造新名词。
